Ce projet, réalisé dans le cadre du module de Programmation Orientée Objet, avait pour 
objectif de concevoir et d’implémenter en Java le jeu Dékal, un jeu de stratégie sur une 
grille 4×4. L’enjeu principal était de construire une architecture modulaire, claire et robuste, 
en appliquant les principes essentiels de la POO : encapsulation, séparation des 
responsabilité et interactions entre objets. 
Le développement a intégré à la fois un mode console et une interface textuelle 
interactive (TUI), permettant une expérience de jeu complète et intuitive.
